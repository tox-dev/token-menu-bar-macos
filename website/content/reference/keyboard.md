title: Keyboard and accessibility
description: Shortcuts, focus navigation, chart readings and tooltip timing.
weight: 6
---

Command-R refreshes, Command-F focuses the Settings model filter, and Escape closes the panel. Enable macOS Keyboard
navigation to move through controls with Tab and Shift-Tab.

Most explanatory tooltips appear after 150 ms and dismiss after 150 ms. History controls wait 1.2 seconds. Tabs and the
chart plot have no text tooltip; use the legend and chart accessibility values for the plotted data.

The status item exposes text readings for its rendered cells. Controls retain accessible labels and values when they use
icons. The chart exposes series, dates and values; its legend supports selecting and hiding series without relying on
colour.

Enable macOS Keyboard navigation for Tab and Shift-Tab. Command-R refreshes, Command-F focuses the Settings model
filter, and Escape closes the panel. Include the source version and the affected control in accessibility reports.
