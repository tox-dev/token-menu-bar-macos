Token Menu Bar is a one-person project, and support happens on its GitHub issue tracker. Ask there for anything these
pages do not answer.

## Ask a question or report a problem

1. Look for the symptom in [Troubleshooting](/troubleshooting/) and on your [provider page](/reference/providers/).
2. Open a [new issue](https://github.com/tox-dev/token-menu-bar-macos/issues/new). Posting needs a free GitHub account.
   **Report Issue** in the app footer opens the same page with your version, distribution channel and recent log lines
   filled in.
3. Read the prefilled text before you post. [Collect diagnostics](/troubleshooting/diagnostics/) lists what it can
   contain, including plan names, usage and local paths.

Issues are public. Leave out tokens, credential files and private transcripts.

## Request a feature

Open an issue and describe the workflow you want to fix. A provider that is missing or reports the wrong quota belongs
there too.

## Report a security problem

Use [GitHub security advisories](https://github.com/tox-dev/token-menu-bar-macos/security/advisories/new) rather than a
public issue. The [security policy](https://github.com/tox-dev/token-menu-bar-macos/blob/main/SECURITY.md) says what to
include.

## Why the maintainer cannot look you up

The app has no account, sends no telemetry and uploads no crash reports, so nothing reaches the maintainer unless you
file an issue. Say which build you run (Direct, Homebrew or App Store) and which provider is involved.
