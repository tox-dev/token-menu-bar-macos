What changed against your reference, and why

  1. No “Usage Site” in the footer — you asked for it gone. Removal spans ProviderID.usagePage, the card button, the plan-chip link and the context menu.
  2. “Check for Updates” and auto-update are absent, not disabled, outside Direct builds. Flip the Build switch above to see the Direct variant.
  3. Sign-in moved out of Usage into Providers — Cursor's card in Usage now points there instead of carrying a CLI hint.
  4. “Windows” is now “Models”, with the model id in monospace beneath the name. Genuine rate-limit windows label themselves window · 7d rather than pretending to be models.
  5. Per-provider refresh intervals kept — they already exist, with per-provider floors.
  6. All six sections present: About, Menu bar, Providers, Data, Notifications, Log. Earlier mockups dropped three of them.
  7. The reference shows only a filename for the history path; this shows the full path, which is more useful when you need to find it.
